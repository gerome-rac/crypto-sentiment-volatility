# Scripts behind the tables, figures and additional analyses of the thesis

These are copies of the scripts as they ran in the thesis working folder. Paths inside them refer to that layout: the
LaTeX project `latex/` next to this repository's folder `code/`, the model runs under `code/data/pipeline/model_runs/`.

- `tables/`: the scripts that wrote the LaTeX tables, with the value files they produced (aggregated results only).
  Where two dated versions of a script exist, the later one wrote the table in the thesis.
- `figures/`: the scripts and input series of the figures.
- `analysis/`: the additional analyses reported in Chapter 6 and Appendix D (placement of the Tether news terms, the
  days that carry the gains, the overlap of the emotion measures with the other regressors, market phases, the polarity
  gain in June 2022, the emotion step across the robustness runs).

No file here contains post texts, post ids or account ids.
